# Blitz project overview

The product definition, target users, feature scope, and acceptance goals live in [`PRD.md`](./PRD.md). Treat that as the canonical product source; this file only records a short orientation to avoid duplicating the PRD.

Blitz is an Expo/React Native NFC Wi-Fi connector. The current app is an Android-first local prototype for configuring a business profile and Wi-Fi, previewing a Wi-Fi QR code, and testing NFC tag reads. Authentication, remote persistence, admin registration, trusted tag verification, and real provisioning remain future work and must not be represented as complete.
